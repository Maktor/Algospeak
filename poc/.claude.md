# Dual-Encoder RBE PoC — Architecture & Workflow

## Architecture Overview

This PoC implements **Rule-Based Embeddings (RBE)** for content moderation, inspired by 
[Seed Paper: "Bridging Symbolic Logic and Neural Networks"](link-to-paper).

### Phase 1: Unfrozen Encoders (Current)
- **Rule Encoder** + **Text Encoder** (both `sentence-transformers/all-miniLM-L6-v2`, 384-dim)
- Both encoders **unfrozen** (fine-tune all ~22M parameters)
- Trainable **contrastive loss head** learns to score (text_emb, rule_exemplar_emb) pairs
- Inference: Cosine similarity; threshold k triggers human review
- Loss function: Contrastive (paired)

### Phase 2: Future Fine-tuning (Optional)
- Retrain on human feedback signals
- Better embeddings adapted to your data distribution

## Code Organization

### Data Pipeline
- `encoder_prep.py`: Load classified_data.csv, downsample to 50K, split 70/15/15, map labels 0/1/2
- `ruleset_matcher.py`: For each text, find fired rules, concatenate exemplars
- Output: (text, rule_exemplars, label) triples

### Model & Training
- `dual_encoder.py`: Unfrozen STS embedders + contrastive loss
- `train.py`: Main loop; trains both encoders + loss head
- `inference.py`: Inference + k-tuning
- `evaluate.py`: Metrics, confusion matrix, ROC curves

### Human Feedback
- `feedback.py`: Export flagged items to CSV, re-import annotated CSV
- Annotators mark `corrected_label` in CSV
- Output: feedback.jsonl for Phase 2 retraining

## How to Run

### Phase 1 Training
```bash
cd poc
python src/encoder_prep.py      # Prepare data splits
python src/ruleset_matcher.py   # Build exemplar pairs
python src/train.py             # Train unfrozen encoders (~30-45 min/epoch)
python src/inference.py         # Inference + k-tuning
python src/evaluate.py          # Generate metrics & ROC plots
```

### Human Feedback Loop
1. `python src/feedback.py --export --threshold 0.85` → creates flagged_for_review.csv
2. Open CSV, manually correct misclassifications in `corrected_label` column
3. `python src/feedback.py --import flagged_for_review_annotated.csv` → feedback.jsonl
4. Once ~500 corrections gathered, move to Phase 2

### Phase 2 Fine-tuning (Post-PoC validation)
```bash
# Update config.yaml: frozen: true (or keep false for full retraining)
python src/train.py --phase 2 --feedback data/feedback/feedback.jsonl
```

## Key Design Decisions

1. **Unfrozen Encoders**: Fine-tune both for better adaptation (slower but more flexible)
2. **STS Model**: Pre-trained on similarity tasks, perfect for our cosine similarity setup
3. **Contrastive Loss**: Pulls similar text-rule pairs closer in embedding space
4. **Multiple k values**: Test thresholds to find optimal review rate
5. **Stratified splits**: Preserve imbalanced class distribution

## Common Issues & Troubleshooting

- **OOM on CPU**: Reduce batch_size in config.yaml (try 8 or 4)
- **Training too slow**: Skip epochs you don't need; sample 30K comments for quick test
- **Low accuracy**: Check exemplar pairing logic; verify rules fire on test texts
- **Threshold not working**: Inspect similarity score distribution; adjust k range
